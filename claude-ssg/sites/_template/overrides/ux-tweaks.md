# UX Tweaks - Template

Ce fichier permet de personnaliser les comportements UX de ce site
sans modifier les composants directement.

## Configuration

### Navigation
```yaml
menu_sticky: false
mobile_menu_style: hamburger
show_breadcrumb: false
```

### Contenu
```yaml
show_dates: true
show_author: false
show_reading_time: false
excerpt_length: 150
```

### Interactions
```yaml
smooth_scroll: true
back_to_top_button: false
```

### Apparence
```yaml
header_style: default
footer_style: default
```

## Notes

- Ces paramètres sont lus par les composants du type de site
- Tous les paramètres sont optionnels
- Les valeurs non définies utilisent les défauts du type de site
