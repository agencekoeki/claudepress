# Bienvenue sur votre nouveau site

Ceci est la page d'accueil de votre site généré avec Claude SSG.

## Premiers pas

1. Personnalisez `site.json` avec vos informations
2. Modifiez cette page d'accueil
3. Créez de nouvelles pages avec `/new-page`
4. Construisez votre site avec `/build`

## Fonctionnalités

- **Thèmes personnalisables** : Changez l'apparence de votre site
- **Types de sites** : Blog, portfolio, documentation...
- **Composants réutilisables** : Construisez vos pages comme des blocs
- **Surcharges locales** : Personnalisez sans toucher aux fichiers originaux

## Commandes utiles

```
/status           → Voir l'état du projet
/build mon-site   → Construire le site
/new-page         → Créer une page
/validate         → Vérifier la configuration
```

Bonne création !
