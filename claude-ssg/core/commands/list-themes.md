# Commande : list-themes

## But
Afficher la liste de tous les thèmes disponibles avec leurs informations.

## Syntaxe
```
/list-themes
```

## Sortie
```
[THÈMES DISPONIBLES]

minimal (v1.0.0)
  Auteur: Claude SSG
  Composants: 18
  Description: Thème minimaliste et épuré

corporate (v1.2.0)
  Auteur: Équipe Design
  Composants: 24
  Description: Thème professionnel pour entreprises

_template
  (Template de base - ne pas utiliser directement)

Total: 2 thèmes utilisables
```

## Informations affichées
Pour chaque thème :
- Nom et version
- Auteur (si spécifié)
- Nombre de composants
- Description courte

## Utilisation
Utiliser cette commande pour :
- Voir les thèmes disponibles avant `/init-site`
- Vérifier les versions des thèmes
- Identifier les thèmes à personnaliser
